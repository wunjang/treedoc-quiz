# 🌳 TREEDOC-QUIZ: 나무의사 기출문제 모아보기
나무의사 자격증 취득을 준비하는 수험생들을 위한 깔끔하고 직관적인 기출문제 뷰어입니다.

🔗사이트 방문하기: [**treedoc-quiz.work.gd**](https://treedoc-quiz.work.gd)

## 📖 이용 방법
- 링크 접속: 상단의 사이트 주소를 클릭합니다.
- 문제 선택: '필터 설정'에서 원하는 회차와 과목을 선택합니다.(동시 선택 가능)
- 학습: 문제를 풀고 정답을 확인하며 자유롭게 학습을 진행합니다.
- 메모: 문제 카드 오른쪽 위 `📝` 아이콘으로 메모를 작성할 수 있으며, `정답 확인` 시 함께 확인할 수 있습니다.

## 🧪 모의고사 모드
- 우측 상단 `☰` 메뉴에서 `모의고사 모드`를 선택합니다.
- 과목을 선택하고 `과목당 문제 수`를 입력한 뒤 `모의고사 시작`을 누릅니다.
- 선택한 과목 기준으로 회차와 무관하게 문제가 무작위 출제됩니다.
- 문항당 1분 기준 타이머가 적용됩니다.
- 진행 중 `일시정지`, `종료` 버튼으로 시험 상태를 제어할 수 있습니다.

## 🔗 데이터 내보내기/가져오기
- 도움말 모달 하단의 `데이터 내보내기` 버튼을 누르면 현재 로컬 데이터가 포함된 URL이 복사됩니다.
- 이 URL을 다른 기기에서 열면 메모(`questionMemos`), 즐겨찾기(`favoriteQuestions`), 다크모드(`darkMode`)가 해당 기기 로컬 저장소로 복원됩니다.
- 새 기기에 기존 로컬 데이터가 이미 있으면 덮어쓰기 여부를 먼저 확인합니다.
- 가져오기가 완료되면 화면이 자동 새로고침되어 적용 결과가 즉시 반영됩니다.
